# El Pollo Loco – Jump & Run Game

El Pollo Loco is a 2D jump-and-run game built with JavaScript and object-oriented programming.

The player controls Pepe through the desert, collects coins and bottles, fights enemies, and ultimately faces the final boss.

## Features

- Character movement and jumping
- Enemy interactions
- Collectable coins and bottles
- Throwable bottles
- Health and status bars
- Final boss fight
- Sound effects and background music
- Keyboard and touch controls
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- Object-Oriented Programming (OOP)
